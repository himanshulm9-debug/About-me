Bare-Metal Arch Linux

Pure Arch Linux Cockpit

"When I installed Arch Linux and executed ping, the package wasn't even there. That taught me the profound truth of Arch: basic packages are optional user choice." Zero bloat, maximum sovereign speed.

⚡ Primary Development Strategy: Bare-metal execution on Arch Linux without virtualization lag. I deconstruct kernel primitives and computer science concepts first, then enter high-velocity vibe coding flow states with non-stop music streaming and AI coding agents.
🐧 Native Linux Apps & Personal Utilities: I build native applications specifically for Linux (e.g. SmallExcel C++20/Qt6 316 KB standalone binary), engineering bespoke operational features for myself to manage multi-account operations, gaming checklists, and workflow automation.
