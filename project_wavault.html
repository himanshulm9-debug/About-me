WhatsApp Vault

"Set it and forget it." A headless backup engine that intercepts chat streams via WebSockets, archiving text to MongoDB and media to Telegram Cloud in real-time.

DELETED MESSAGE RECOVERED

The Problem

Standard cloud backups (Google Drive/iCloud) are periodic and monolithic. If you lose your phone between backups, that data is gone. More importantly, they respect the "Delete for Everyone" protocol.

If someone sends a crucial message and deletes it 5 minutes later, it disappears from your device forever. I needed a system that prioritized **record-keeping over protocol compliance**.

The Solution

I engineered a "headless client" using the **Baileys** library. It acts as a ghost device linked to your WhatsApp account. It listens to the WebSocket stream 24/7 on a secure server.

Every incoming text is instantly indexed in MongoDB. Every image or video (up to 45MB) is tunneled to a private Telegram channel for infinite, free cloud storage. It requires zero interaction after the initial QR scan.

Socket interception and dual-cloud storage architecture.

Baileys Socket

A reverse-engineered WebSocket client that emulates a WhatsApp Web session. It maintains a persistent connection without a browser, using minimal RAM (runs on Alpine Linux).

Telegram Tunneling

Storing media in a database is expensive. I utilize Telegram's generous Bot API to offload media storage. The app pipes data streams directly from WhatsApp to Telegram without saving files locally.
