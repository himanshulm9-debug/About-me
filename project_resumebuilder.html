Talent Forge

A dual-interface platform bridging administrative control with public presentation. Empowering institutions to manage and showcase top talent through dynamic, data-driven portfolios.

The Problem

Managing professional profiles for an organization is often chaotic. Resumes come in various formats (PDF, Docx), designs are inconsistent, and data is trapped in static files, making it impossible to search or filter candidates effectively.

Updating a single detail requires re-uploading entire documents. There was no centralized way to showcase talent with a unified, professional brand identity.

The Solution

I built a centralized ecosystem. The Admin Pane (restricted access) allows for structured data entry—converting skills, education, and experience into pure JSON. It features a built-in image cropper to ensure uniform profile photos.

The Public Showcase reads this structured data to generate beautiful, interactive resume cards on the fly. It enables instant filtering by skills or location and includes a one-click "Download PDF" feature generated directly from the live data.

Under the Hood

A full-stack solution focusing on data integrity and presentation.

Node.js Backend

A robust Express server manages the JSON database. I implemented a file-based storage system for portability and secure API key authentication to protect the Admin routes from unauthorized access.

Express FS Module

Image Processing

Integrated Cropper.js in the admin dashboard. This ensures that every profile picture uploaded is perfectly square and optimized before being saved to the server, maintaining visual consistency across the showcase.

Cropper.js Base64

Dynamic PDF

Used jsPDF to generate downloadable resumes client-side. The system takes the JSON data and draws a clean, printable PDF document instantly, removing the need for users to manually format Word documents.
